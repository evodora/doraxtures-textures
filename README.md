# Doraxtures — public texture assets

Texture-pack image assets for [doraxtures.site](https://doraxtures.site).
Public so they can be served straight from a CDN with no token.

## Serving

**jsDelivr (primary — global CDN, no bandwidth cap):**
```
https://cdn.jsdelivr.net/gh/evodora/doraxtures-textures@main/packs/<pack>/<file>
```

**GitHub Pages (fallback):**
```
https://evodora.github.io/doraxtures-textures/packs/<pack>/<file>
```

Layout mirrors the old `doraxtures.site/packs/...` paths exactly, so the
extension's redirect rules only need the base URL swapped.
